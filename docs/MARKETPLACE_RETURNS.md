# Marketplace physical return foundation
07-return-receipts.sql introduces an accepted physical return receipt ledger, reusing existing OrderItems and InventoryBalances/Transactions. Trusted internal service only, not directly exposed to customers/vendors. Paid parent, verified payment metadata, consumed reservation and purchased quantity are required. Partial returns capped cumulatively by sold quantity; same receipt request retry is idempotent; altered retry rejected. This is NOT customer return authorization, refund calculation, settlement reversal, return shipping or damaged-stock disposition. Actor/approval linkage, return request UI and authorization must be implemented before exposing any operation. Refund, tax/discount allocation and commission policy require approved business rules. Test fixture exercises stock only. No production activation.
