# Security and UI simplification — first pass
Base audit 8fdd3c3. Staff order-operation reauthentication now uses the same StaffPassword verifier and explicit legacy setting as staff login; no new password format. Admin-only restriction on Products, Report and ManageCustomer aligns with the current admin sign-in role, prevents customer cookie access. Image delete and customer status/password writes require CSRF; image delete reuses AdminFeedback, updates only confirmed deleted thumbnail and preserves unsaved fields. Existing image deletion remains immediate, not an edit-save transaction. Removed obsolete product/subcategory/permission/coupon grids, serialized models and unnecessary dependencies; retained current server paging and search; removed forced height on permissions/coupons, duplicate jQuery on deals and Bootstrap on customers. Build and browser verification required. Customer password hashing, mobile API identity, OTP and payment remediation remain open; no production cutover.
