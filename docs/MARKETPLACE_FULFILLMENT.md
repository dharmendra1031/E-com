# Fulfillment and payment review
Apply 08-vendor-fulfillment.sql after payment/return migrations. Existing vendor order screens now read fulfillment state. Marketplace__VendorFulfillmentEnabled and Marketplace__PaymentReviewEnabled are OFF by default. Vendor owner/manager may mark verified paid own order Packed then HandedOver; staff read-only. SQL rechecks membership and payment, serializes state changes, records actor and UTC time and rejects skipped/stale steps. Identical current-state retry is safe. Handover is a human attestation, not a carrier API or delivery proof. Delivered status reserved for future authorized delivery confirmation; no automatic payout. Admin payment review is read-only and uses existing superadmin policy, showing pending order/attempt data, not gateway verification. No commission or settlement rules assumed. SQL regression tests use disposable DB. HTTP/browser acceptance, delivery evidence, customer tracking, actual gateway refund and release remain pending.
