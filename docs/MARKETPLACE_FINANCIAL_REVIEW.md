# Vendor financial review and refund evidence
Install 12-refund-review.sql after finance preview. Vendor owner-only finance review reuses the same financial table as superadmin; membership is checked in the actual SQL read. No staff/manager commission access, no payable balance or withdrawal. Superadmin refund review correlates original paid invoice/payment, line-level received return and matching physical receipt. Merchandise value is informational only; shipping, VAT, fees, refund policy, gateway verification and settlement reconciliation must be approved before funds movement. No refund ledger or payout operation is created, no external transfer. Both screens use FinancePreviewEnabled, default OFF. Test verifies known paid physical evidence and excludes other rows. Browser/runtime, real gateway and financial policy approval remain release gates.
