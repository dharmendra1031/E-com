# Customer order recovery and cancellation
09-customer-orders.sql creates read-only order status view; install after fulfillment schema. Development-only checkout flags guard customer order history and receipt. All reads scope to verified current customer. Receipt shows vendor suborders and recorded fulfillment, with distinct pending/uncertain/released states; a linked invoice can be verified rather than started again. Cancellation only releases an order that has never started payment; same cancellation is retryable and blocks later payment. Does not put quantities back in cart or claim refund. No automatic release job or commercial cancellation master status assumed. SQL tests verify actual reservation release, cross-customer restriction and no duplicate release. HTTP/browser and real gateway still pending.
