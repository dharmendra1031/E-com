# Customer marketplace offer preview
Install inventory migrations and scripts/marketplace/marketplace-offers.sql on a restored test database. Marketplace__CustomerOfferPreviewEnabled defaults to false. Enable only in an isolated environment after schema checks and reconciliation. Existing product detail uses one SQL view of approved vendors/listings, active products and positive listing availability. 20 offers per page ordered by price and listing ID. Selection is comparison only, scoped to current product/page. Legacy checkout, discounts, stock, prices and cart stay unchanged. No private seller data exposed. Prices and stock are point-in-time, not reservations. Actual seller purchases require listing-keyed cart, immutable order snapshots, verified payment and checkout integration. Category/home/brand/search seller summaries and sorting remain pending. EF query execution and browser tests pending. Do not enable publicly before business and security acceptance.

## Catalog preview — phase 9B
Category, brand (existing ProductPartial), and search result grids use grouped eligible offers for price sorting, range filtering and stock-only filtering before pagination. Products without offers stay visible unless filtered, sort last in price order and have no seller price. Preview grid links to detail instead of sending a seller price to legacy cart. Home featured and weekend cards show separately labelled seller summary; promotions and legacy purchase price remain unchanged. Autocomplete still uses legacy data. One grouped query per home section, no per-card query. Actual EF SQL translation, plans, localization and browser checks pending. Seller checkout remains disabled; no production cutover.
