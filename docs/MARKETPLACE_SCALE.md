# Marketplace scale benchmark
Run the Marketplace SQL scale benchmark workflow in GitHub Actions. It creates a fresh disposable SQL Server with one million synthetic products and two million seller listings, reuses actual marketplace/inventory schema and public offer view, and records SQL elapsed time and IO for product offers, category/price filter, deep OFFSET pagination, and substring search. No production database or data is used. The synthetic schema intentionally omits reviews, media, legacy stock, ORM/HTTP and concurrent customer load, so it is a query benchmark, not end-to-end performance certification. No speed threshold asserted without a measured baseline and agreed SLA. Use the artifact/log to identify actual bottlenecks before adding indexes or changing search.
