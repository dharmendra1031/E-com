# Marketplace finance preview
Install 11-vendor-finance.sql after return workflow. Marketplace__FinancePreviewEnabled defaults false. Explicit vendor rate, versioned append-only policy (no seeded default); 0% only if deliberately saved. Superadmin application policy plus active Admin database actor; stale policy updates rejected. During original development checkout, snapshot all vendor rates and rounded commission on merchandise subtotal only, excluding VAT/delivery. Missing policy rolls back complete order; legacy/test orders created before enabling stay unsnapshotted and are not backfilled. Calculation basis and three-decimal rounding are proposed test rules, not approved commercial terms. Finance review only shows paid suborder merchandise and commission; return history flags financial review. Not a settlement balance, liability posting, payout approval, or refund. No actual funds transferred. Need approved commission basis (category overrides etc.), VAT/fees/shipping allocation, refund/reversal policy, settlement cycle and gateway supplier capabilities, immutable accounting journal/payout evidence, concurrency and browser acceptance before activation.
